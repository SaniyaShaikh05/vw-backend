# VitalWatch

## Real-Time IoT Health Monitoring System

VitalWatch is an IoT-based health monitoring platform designed to collect and monitor health data in real time and provide meaningful insights through a connected system.

## Features

- Secure user authentication
- RESTful backend APIs
- User and doctor management
- Database integration
- Health data management
- Scalable backend architecture
- Real-time health monitoring support

## Tech Stack

- Python
- FastAPI
- PostgreSQL / Supabase
- SQLAlchemy
- Alembic
- JWT Authentication
- Redis
